Zoned

Citation-grounded Document Q&A · 07/2026 – Present

Repo

A retrieval-augmented generation (RAG) system that answers questions using only a set of uploaded documents, and explicitly refuses when the answer isn't there.

Upload a set of PDFs, ask a question, and Zoned retrieves the relevant passages, answers from those passages alone, and cites the document and page behind every claim. PDFs are parsed with Docling, embedded with the OpenAI API, and answered by the Claude API.

Everything lives in a single PostgreSQL + pgvector schema (documents, chunks, and 1536-dim embeddings), with retrieval written as raw SQL over psycopg 3, an HNSW cosine index, a generated tsvector column, and Alembic migrations. Ingestion is idempotent: SHA-256 content hashing lets renamed or duplicated files skip re-parsing, and per-document transactions isolate mid-batch failures, cutting re-runs to seconds.

On a 33-question evaluation set it scored 23/23 document-level recall, 19/23 top-1 attribution, 10/10 correct refusals, and zero fabricated answers, with every ranking miss traced to nearly identical document pairs.

ML Experiments

Self-Directed Deep Learning Research · 10/2026 – Present

Repo

A course assignment extended into my own experiment: what's the best way to adapt an ImageNet-pretrained ResNet-18 to 10 PASCAL superclasses?

I compared two approaches: averaging the head weights of each superclass's ImageNet subclasses, versus summing the subclasses' softmax probabilities. Probability summing won both zero-shot (95.6% vs. 92.4%) and after head-only fine-tuning (96.9% vs. 95.3%), and came out ahead on all 3 seeds.

Then I added an "others" class for the 774 ImageNet classes that don't map to any superclass, and the result reversed: probability summing dropped to 88.9% while weight averaging held at 95.3%.

Momentum

Task Planner with Natural-Language Parsing · 04/2026 – 09/2026

Live Demo

Repo

A full-stack task planner to keep you focused on what's important.

Create, edit, categorize, and track tasks by deadline, with the closest upcoming deadline always front and center. A Spring Boot REST backend serves a React frontend, deployed on Railway behind a Docker build.

Type a task in plain English and the Claude API fills in the title, category, and deadline through a forced tool schema for validated output. You confirm before anything is saved, and it falls back to your raw input if the API is unavailable.

Under the hood, a normalized MySQL schema makes the next task a direct indexed lookup (verified with query plans) and each edit writes one row; foreign keys prevent orphaned tasks, and transactions make reordering all-or-nothing.

ReLeaf

Hack the Coast · 1st Place & Best Use of Gemini API · 02/2026

Live Demo Backend API

Demo Video

Repo

A 3D urban-heat planner that helps cities combat the Urban Heat Island effect.

ReLeaf maps Vancouver's surface temperatures and projects the cooling, CO2 offset, and ROI of placing trees, cool roofs, and bio-swales. A FastAPI + Rasterio backend handles per-pixel temperature lookups and hotspot ranking, validating placements against OpenStreetMap data.

Gemini renders the planned interventions into real Street View images (cached in Supabase) and drafts FEMA grant narratives from the simulation results.
